# 计算器 PWA

离线可用的标准计算器（参考 Windows 计算器深色主题），部署于 GitHub Pages。

## 功能
- 标准四则运算（+ − × ÷）、%、√、x²、1/x、±、退格
- 记忆功能：MC / MR / M+ / M− / MS
- 历史记录：位于数字键盘上方，显示完整运算等式与结果，点击或「复制」按钮即可复制结果，历史本地持久化
- PWA 离线：Service Worker 全量缓存，添加到主屏幕后飞行模式可用

## iPhone 安装（飞行模式使用）
1. 用 Safari 打开本站
2. 点「分享」→「添加到主屏幕」
3. 之后从主屏幕图标打开，飞行模式下也能使用（首次打开需联网）

## 技术
纯 HTML/CSS/JS，无依赖，无构建步骤。
